# YouTube rules

Use `agency/youtube/longs/`, `mids/`, and `shorts/`. ISO-date every video/source folder and use kebab-case slugs. Longs contain `video-card.md`, `thumbnail/`, and `script/`; mids group multiple cuts under one dated source folder; shorts each receive their own dated folder and a source/timecode record. Never leave production assets loose at a tier root.
